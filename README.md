# SteelQuote — نظام إدارة وتسعير ورش الحدادة وعروض الأسعار

**SteelQuote** هو تطبيق ويب مصمم خصيصاً لأصحاب ورش الحدادة والتصنيع المعدني لحساب تكاليف الأعمال والتصنيع (الخامات، المصنعية، الهالك، المصاريف الإدارية) وتوليد عروض أسعار احترافية وحساب هامش الربح تلقائياً مع دعم كامل للغة العربية (RTL).

---

## 🚀 المميزات الرئيسية

1. **إدارة الخامات والمستلزمات:**
   - إضافة، تعديل، وحذف الخامات مع تحديد وحدة القياس (متر، كجم، قطعة، لوح...) وسعر الوحدة.
   - اختيار الخامات مباشرة في العرض مع استدعاء تلقائي للوحدة والسعر.

2. **إدارة العملاء:**
   - سجل كامل للعملاء يتضمن الأسماء، أرقام الهواتف، البريد الإلكتروني والعناوين.

3. **حاسبة تكلفة وهامش ربح متكاملة:**
   - حساب إجمالي تكلفة الخامات تلقائياً عبر واجهة تفاعلية.
   - إضافة تكلفة المصنعية / أجور العمالة والمصاريف الإدارية والنقل.
   - تطبيق نسبة هامش الربح المقترحة (%) واحتساب مبلغ الربح وسعر البيع النهائي للعميل بدقة.

4. **إدارة عروض الأسعار (Quotations Module):**
   - إنشاء عرض سعر متكامل برقم تسلسلي فريد تلقائي (مثل `SQ-2025-0001`).
   - إضافة بنود خامات مفتوحة وديناميكية.
   - تحديد حالة العرض (مسودة، مرسل، مقبول، مرفوض) مع إمكانية التغيير السريع.
   - تحديد تاريخ صلاحية العرض وإضافة ملاحظات وشروط دفع باللغة العربية.

5. **توليد ملفات PDF وطباعة احترافية:**
   - تصميم عرض سعر احترافي جاهز للطباعة والتصدير كملف PDF.
   - دعم كامل ومتوافق للغة العربية الاتجاه من اليمين إلى اليسار (RTL).
   - متوافق مع كافة المتصفحات والطابعات.

6. **لوحة تحكم إحصائية (Dashboard):**
   - عرض إجمالي عروض الأسعار وقيمتها الإجمالية.
   - إحصائيات حول العروض المقبولة والعروض قيد الانتظار.
   - توزيع الحالات وجدول بأحدث عروض الأسعار مع أزرار الإجراءات السريعة.

## 📋 متطلبات التشغيل

- **PHP**: إصدار `7.4` أو أحدث (`PHP 8.x` موصى به).
- **قاعدة البيانات**: `MySQL` أو `MariaDB`.
- **بيئة التشغيل**: `XAMPP` / `WAMP` / `Laragon` أو أي خادم `Apache` / `Nginx`.

---

## 🛠️ خطوات التثبيت والتشغيل

1. **تنزيل المشروع:**
   ضع مجلد المشروع `steelquote` داخل مجلد المستندات لخادم الويب (مثل `C:/xampp/htdocs/steelquote`).

2. **إعداد قاعدة البيانات:**
   - قم بفتح `phpMyAdmin` أو بيئة إدارة MySQL.
   - قم باستيراد ملف `database.sql` المرفق مع المشروع، أو تنفيذ الأمر:
     ```sql
     SOURCE database.sql;
     ```
   - ملف `database.sql` يحتوي على الهيكل الكامل لقاعدة البيانات بالإضافة إلى **بيانات تجريبية (Demo Data)** شاملة للخامات، العملاء، وعروض الأسعار.

3. **ضبط إعدادات الاتصال (`config/db.php`):**
   قم بفتح ملف `config/db.php` وتأكد من مطابقة بيانات منفذ وباسورد MySQL:
   ```php
   define('DB_HOST', '127.0.0.1');
   define('DB_PORT', '3306'); // أو 3307 حسب إعدادات XAMPP لديك
   define('DB_USER', 'root');
   define('DB_PASS', '');
   define('DB_NAME', 'steelquote');
   define('BASE_URL', '/steelquote/');
   ```

4. **تشغيل النظام:**
   افتح المتصفح وانتقل إلى الرابط:
   `http://localhost/steelquote/`

## 🎯 بيانات تجريبية (Demo Data)

عند استيراد `database.sql` ستجد بيانات تجريبية جاهزة للاختبار:
- **خامات محددة مسبقاً:** علب حديد، كميرات IPE 160، صاج ساندوتش بانل، زوايا حديد، فورفورجيه، دهانات، ومستلزمات لحام.
- **عملاء تجريبيون:** شركات مقاولات، مهندسين، وأصحاب فيلات ومصانع.
- **عروض أسعار تجريبية:** عروض أسعار شاملة البنود مع حاسبة المصنعية والربح وتوليد PDF.
